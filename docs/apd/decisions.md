# Decisions

## D-001: ビルドツール導入によるファイル分割
- **Date**: 2026-02-11
- **Context**: プロダクトは全て `index.html` 1 ファイルに含まれていた（CSS、HTML、JS、データ）。多言語対応・コスト計算ツール・ライト/ダークモード追加により、コード量が大幅に増加する見込み（1700 行 → 3000 行超）。Design 文書で「ビルドツールの導入は許容するが、最終出力は静的サイトとする」と方針決定済み。
- **Options**:
  - 1: 単一 HTML を維持 — 全てを 1 ファイルに含める
  - 2: ビルドツール導入で分割 — 開発時はファイル分割し、ビルドで結合
  - 3: 複数ファイル構成 — CSS / JS / データを分離し、個別にロード
- **Decision**: 2: ビルドツール導入で分割
- **Reason**:
  - 開発時は CSS / JS / 翻訳データ / GPU_DATA を個別ファイルに分離し、メンテ性を確保
  - ビルド時に全てインラインで結合し、最終出力は単一 HTML を維持
  - Design 文書の方針と整合
  - 単一 HTML 維持により、ポータビリティ（保存・共有の容易さ）も損なわない
- **Refs**: 旧 Project Contract v1（現行モデルで廃止。git 履歴に残る）
