Notes

  • 価格: us-east-1 (バージニア北部) の On-Demand 価格 (USD)。CB = Capacity Blocks（東京リージョン優先、未提供時は米国リージョン）。価格基準: %PRICING_AS_OF%。
  • 価格リージョン: ヘッダのリージョン選択で、価格列と計算ツールの金額が切り替わります。
  • G7e (NEW): G7e は NVIDIA RTX PRO 6000 Blackwell Server Edition、G7 は RTX PRO 4500 Blackwell Server Edition を搭載。
  • P5en vs P5e vs P5: P5en: H200 + EFAv3 + PCIe Gen5...
  • EFA: Elastic Fabric Adapter。マルチノード分散学習に必須。
  • PCIe: Gen5はGen4の約2倍の帯域幅。
  • FP16/FP8/FP4: TFLOPS値。
  • GB300: P6e-GB300 UltraServer（GB300 NVL72、GPU 72 基）は AWS が発表済みですが、インスタンス型名と価格が未公開のため表には載せていません。
